# ESP32P6

Первый этап проекта — проверить сборку ESP-IDF для `ESP32-P4` и запуск
приложения с сообщением:

```text
Привет, это я, Маша
```

Добавлен главный экран осциллографа: шесть цветных плиток в альбомной раскладке
800×480 — `ОСЦИЛЛОГРАФ`, `НАСТРОЙКИ`, два пункта `РЕЗЕРВ`, `ПОМОЩЬ` и
`О ПРОГРАММЕ`. Текст нарисован сглаженными кириллическими глифами Noto Sans.
Нативная панель работает в портретных координатах 480×800, поэтому кадр
поворачивается при отрисовке. Версия со сглаженным шрифтом записана и проверена
на экране владельцем; контроль образов Flash прошёл, резервная копия сохранена
в `device_backups/flash-16MB-20261006-200428-215527536.bin`.
Касания CST3530 ещё не обрабатываются: точные линии I²C/сброса для фактической
ревизии платы нужно подтвердить по схеме. Экранный ввод 0–5 В также требует
аналогового делителя и защиты; подключать 5 В прямо к GPIO нельзя.

Сборка настроена для ранней ревизии ESP32-P4, Flash 16 МБ, CPU 360 МГц и
PSRAM 32 МБ (HEX, 200 МГц). PSRAM нужна дисплейному framebuffer размером
768 КБ. Перед
записью `run flash` проверяет чип и реальный объём Flash, сохраняет полный
дамп в `device_backups/`, записывает образы и выполняет их проверку. Все
сообщения скрипта дублируются в `out.txt`.

## Сборка

Рекомендуемое окружение описано в `PROJECT.md`:

```bash
source /home/oleg/esp/ESP-IDF-dev-6.1/export.sh
idf.py set-target esp32p4
idf.py build
```

После согласования владельцем прошивку запускают из корня проекта:

```bash
bash ./run flash
```

Проверка хэшей образов после последней записи прошла. Владелец отдельно
подтвердил загрузку меню и читаемость шрифта на дисплее; UART-лог именно этой
загрузки ещё не снимался.

Для короткого чтения загрузочного лога используй `bash ./run monitor`; команда
сохраняет UART-вывод в `out.txt` и сама перезапускает плату через RTS.

`main/display_st7701.c` содержит ручную инициализацию ST7701S и главный экран
меню. Команды настройки панели взяты из открытого BSP
`ultramcu/guition-jc4880p4-bsp` и должны быть проверены на фактическом модуле.
