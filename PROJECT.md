# ESP32P6
Плата разработки:
Процессор - JS-ESP32P4M3 ESP32P4NRW32  32psram wi-fi  esp32p6
CST3530 — это специализированный контроллер емкостного сенсорного экрана (Capacitive Touch Controller) от компании Hynitron (серия CST66xx / CST3x)

## Плата и периферия

- Модуль платы: `JS-ESP32P4M3`.
- Микроконтроллер: `ESP32P4NRW32`.
- Оперативная память: 32 МБ PSRAM.
- Беспроводная часть: Wi‑Fi через ESP32-C6 на плате.
- Сенсорный контроллер: `CST3530`, семейство Hynitron `CST66xx / CST3x`.
- Целевой первый результат: вывести на дисплей текст `Привет, это я, Маша`.

По фотографии `8383145842.webp` визуально подтверждены:

- плата семейства `JC-ESP32P4-M3`;
- модуль `ESP32P4 + ESP32-C6`;
- два разъёма USB Type-C: `Full-speed Type-C` и `High-speed Type-C`;
- разъём I²C `HS 1.0`;
- гребёнка `2×13` с шагом 2,54 мм;
- разъёмы UART, RS-485, камеры, динамика и аккумулятора.

По этой фотографии ещё нельзя надёжно определить модель LCD-панели,
MIPI-DSI распиновку и назначение кнопок `BOOT/RESET`; эти сведения не
подставлять в конфигурацию проекта без отдельного подтверждения.


Проверено локально: окружение активируется, `idf.py` запускается, target
`esp32p4` доступен.

Запасной каталог ESP-IDF:

```text
/home/work/ESP-IDF
```

В нём находится ESP-IDF `v6.0.2`, но на текущем компьютере активация окружения
останавливается из-за отсутствующего инструмента `xtensa-esp-elf`. До ремонта
окружения этот вариант не использовать.

Источник примеров и BSP:

```text
https://github.com/espressif/esp-bsp
```

Для дисплея использовать структуру ESP-BSP/LVGL. Для CST3530 предусмотрен
отдельный компонент `esp_lcd_touch_cst3530`; GPIO, интерфейс дисплея и
параметры панели нужно подтвердить по документации конкретной платы до
сборки прошивки для устройства.

## Правила безопасности

- Сначала собирать и проверять проект локально.
- Не выполнять прошивку, стирание Flash и изменение boot-перемычек без
  отдельного согласования.
- Перед прошивкой подтвердить модель платы, USB-порт и режим загрузчика.
- Одобренная прошивка запускается `bash ./run flash`: скрипт проверяет ESP32-P4
  и Flash 16 МБ, сохраняет полный дамп в `device_backups/`, затем записывает и
  проверяет bootloader, таблицу разделов и приложение. `out.txt` содержит весь лог.
- Разделять успешную сборку, запись во Flash, загрузку прошивки и рабочий
  вывод на дисплей.
- Не добавлять в Git ключи, токены, пароли, `.env` и device-specific дампы.
